# 보조금사업 수행 지출결의 통합관리 프로그램 — PRD

- **문서 버전:** 1.1
- **문서 작성일:** 2026-11-13
- **제품 형태:** Microsoft Excel 기반 통합관리 프로그램
- **대상 사용자:** 여러 보조금 사업을 운영하는 기관의 사업 담당자, 회계 담당자, 검토·승인 담당자, 관리자
- **문서 상태:** 사용자와의 5개 요구사항 질문 및 추가 요청을 반영한 개발용 초안

## 1. 제품 개요

### 1.1 목적

여러 보조금 사업의 **사업 등록 → 예산 편성 및 관리 → 지출결의서 작성 → 사업비 항목별 필수 증빙서류 안내·첨부 관리 → 결재 상태 관리 → 집행 실적 집계 → 정산 보고**를 하나의 Excel 기반 프로그램에서 처리한다.

### 1.2 주요 문제

- 사업별 예산 및 집행 내역을 별도 파일로 관리해 현황 파악과 정산에 시간이 든다.
- 지출결의서를 반복 작성하면서 동일 정보를 중복 입력한다.
- 사업별·비목별 예산 잔액과 집행률을 수동 계산해 오류가 발생할 수 있다.
- 보조금 사업 및 사업비 항목에 따라 필요한 증빙서류가 달라 누락 가능성이 있다.
- 영수증·계약서 등 증빙파일과 지출결의서의 연계가 어렵다.
- 지출결의의 검토·승인·반려 상태를 일관되게 관리하기 어렵다.
- 정산 보고서 작성 시 여러 데이터를 다시 취합해야 한다.

### 1.3 목표

1. 여러 사업의 예산·집행 정보를 사업별로 분리해 통합 조회한다.
2. 지출결의서 입력, 검토, 출력 과정을 표준화한다.
3. 사업별·사업비 항목별 **필수 증빙서류 목록을 자동 안내**하고 첨부 여부를 확인한다.
4. 예산 잔액·집행률을 자동 계산하고 초과 위험을 경고한다.
5. 정산·보고용 자료를 빠르게 추출한다.
6. 코딩 경험이 없는 사용자가 엑셀 화면만으로 기본 업무를 처리할 수 있게 한다.

## 2. 확정된 사용자 요구사항

| 번호 | 질문 주제 | 사용자 답변 | 제품 반영 방향 |
|---|---|---|---|
| 1 | 프로그램의 주된 목적 | 예산·지출결의·증빙·정산 통합 관리 | 단일 통합 업무 흐름 |
| 2 | 사용자 | 여러 보조금 사업 운영 기관 | 사업별 관리 및 역할 구분 |
| 3 | 지출결의 작성 방식 | 입력·증빙 첨부·결재·문서 출력 모두 | 결의서 작성부터 출력까지 지원 |
| 4 | 예산 관리 범위 | 총예산·잔액, 비목별 예산, 초과 방지, 통계 모두 | 예산 집계·경고·대시보드 |
| 5 | 사용 형태 | 엑셀 기반 프로그램 | Excel 시트·수식·표 중심 구현 |
| 추가 | 사업비별 필요서류 | 지출결의서 작성 시 해당 사업비에 따른 필요서류 첨부 | 항목별 서류 기준 설정, 자동 안내, 파일 링크, 누락 검증 |

> **확정 범위와 설계 제안 구분:** 위 요구사항은 사용자에게 확인된 내용이다. 이하 구체적인 필드·시트·흐름·검수기준은 실제 제작을 위해 제안한 기본 설계이며, 지원기관 지침 등에 따라 조정할 수 있다.

## 3. 사용자와 권한

| 사용자 역할 | 주요 업무 |
|---|---|
| 관리자 | 사업 등록, 기초 코드·증빙 기준 설정, 전체 사업 현황 관리 |
| 사업·회계 담당자 | 사업별 예산 입력, 지출결의서 작성, 증빙자료 연결, 정산자료 작성 |
| 검토·승인 담당자 | 지출결의 내용 검토, 승인·반려 상태 및 사유 기록 |

**중요 제약:** 엑셀의 시트 보호, 입력 제한, 담당자 표시 등은 업무 편의를 위한 기능이지 강력한 접근 제어나 법적 효력을 가진 전자서명을 제공하지 않는다. 실제 사용자 인증, 분리 권한, 전자결재 증적이 필수라면 별도 시스템 또는 외부 결재 프로세스가 필요하다.

## 4. 주요 업무 흐름

1. **사업 등록:** 사업명, 기간, 지원기관, 보조금·자부담, 담당자 등록.
2. **예산 편성:** 사업별·재원별·비목별·세목별 예산 및 변경 내역 등록.
3. **지출결의 작성:** 사업과 예산 항목 선택 후 거래처·지출 내용·금액 등 입력.
4. **필요서류 자동 표시:** 선택한 사업 및 사업비 항목의 증빙 기준을 조회해 필수·선택 서류 표시.
5. **증빙 첨부 관리:** 파일을 지정 폴더에 저장하고 엑셀에서 해당 파일에 대한 경로·하이퍼링크 등록, 누락 여부 확인.
6. **결재 상태 관리:** 작성 중 → 결재 요청 → 검토 중 → 승인 또는 반려. 누락 서류 및 예산 초과 여부 검증.
7. **집행 관리:** 승인 및 실제 지급 여부를 구분해 기록하고, 확정된 집행액을 예산 현황에 반영.
8. **정산·출력:** 지출결의서 및 집행·증빙·정산 목록을 Excel/인쇄/PDF 형태로 출력.

## 5. 기능 요구사항

### F-01. 보조금 사업 등록 및 관리 — 필수

- 사업 ID 자동 부여 및 중복 방지
- 사업명, 지원기관, 사업 기간, 총사업비, 보조금, 자부담금, 담당자, 진행 상태 입력
- 사업별 검색·수정·조회
- 각 데이터가 사업 ID를 통해 연결되도록 설계

### F-02. 예산 편성 및 관리 — 필수

- 사업 ID, 재원 구분(보조금·자부담), 비목, 세목, 최초 예산, 증감액, 현재 예산 관리
- 예산 변경 내역 및 변경 사유 기록
- 승인된 지출액, 지급 완료액, 결재 대기 금액을 구분해 표시
- 잔액 및 집행률 자동 계산
- 지출 요청 시 예산 초과 또는 초과 예상 경고
- 사업별·비목별·세목별·기간별 집계

**기본 계산 정의**

- 현재 예산 = 최초 예산 + 예산 증감액 합계
- 승인 기준 잔액 = 현재 예산 − 승인된 지출액
- 승인 기준 집행률(%) = 승인된 지출액 ÷ 현재 예산 × 100
- 현재 예산이 0이면 집행률은 빈칸 또는 0으로 처리하고 오류값은 표시하지 않음

※ 실제 회계상 집행 인정 시점 및 보조금별 정산 규정은 향후 사업 지침에 따라 확정한다.

### F-03. 지출결의서 작성·조회·출력 — 필수

**입력 항목(제안):**

- 지출결의 번호(자동 생성), 사업 ID 및 사업명
- 작성일, 지출 예정일, 실제 지출일
- 재원 구분, 예산 비목·세목
- 지출 목적·내용, 거래처·지급 대상, 지급 방법
- 공급가액, 부가가치세, 총액
- 작성자, 결재 상태, 승인자 및 승인일
- 첨부 증빙 목록 및 누락 상태

**동작:**

- 사업 선택 시 해당 사업의 예산·비목·세목 목록을 제공
- 입력값 필수 여부, 날짜 및 금액 형식 검증
- 지출결의 번호 자동 부여(예: `2026-사업001-지출0001`)
- 결의서 등록·수정·조회·검색
- 인쇄 전용 표준 양식에 입력값 자동 연결
- Excel 인쇄 및 PDF 저장 기능 제공(자동 PDF 일괄 생성은 2차 고도화 가능)
- 승인 완료 기록은 임의 변경을 최소화하도록 관리하고 수정 내역 또는 정정 방식 정의

### F-04. 증빙자료 연결·첨부 상태 관리 — 필수

- 세금계산서, 카드·현금 영수증, 견적서, 거래명세서, 계약서, 지급 확인 자료 등 등록
- **실제 파일을 엑셀 셀에 직접 업로드하는 방식이 아니라**, 지정된 폴더 또는 승인된 공용 저장소에 보관하고 파일 경로/하이퍼링크를 등록하는 방식을 1차 권장
- 결의서 번호, 서류 종류, 파일명, 파일 경로, 등록일, 담당자, 첨부 상태 기록
- 첨부파일 링크 열기, 등록 내역 조회, 누락 표시
- 파일 이동·이름 변경에 의한 링크 손상 가능성을 고려해 폴더 구조와 파일명 규칙 관리

### F-05. 결재 상태 관리 — 필수

- 기본 상태: `작성 중`, `결재 요청`, `검토 중`, `승인`, `반려`
- 요청자·검토자·승인자·요청일·승인일·반려 사유 기록
- 필수 증빙 누락 시 경고, 결재 요청 가능 여부 표시
- 예산 초과 여부 안내
- 승인 전 금액과 승인 후 금액을 구분해 집계
- 실제 전자서명, 자동 결재 메시지 전송 등은 별도 확장 범위

### F-06. 통합 대시보드 및 통계 — 필수

- 전체 사업 수, 진행 중 사업 수
- 총예산, 승인 집행액, 실제 지급액, 잔액, 집행률
- 결재 대기 건수, 증빙 누락 건수
- 사업별 예산 대비 집행액 그래프
- 비목별 집행 현황, 월별 지출 추이
- 사업·기간 선택에 따른 필터

### F-07. 정산 및 보고서 — 필수

- 사업별·재원별·비목별·세목별 지출 실적 자동 집계
- 미집행 잔액 및 집행률 계산
- 결의서 번호와 연동된 증빙 목록 출력
- 정산용 명세서 및 집행 실적표 Excel 출력
- 인쇄 및 PDF 저장
- 지원기관별 정산양식은 향후 템플릿으로 추가할 수 있게 구조화

### F-08. 기초 설정 — 필수

- 담당자, 사업 유형, 재원, 비목·세목, 지급 방법, 결재 상태 코드 관리
- 목록 선택형 입력을 통해 명칭·표기 오류 감소
- 지원기관·사업별 서로 다른 기준을 관리할 수 있게 확장 가능하게 구성

### F-09. 사업비 항목별 필요 증빙서류 자동 안내 및 첨부 관리 — **최우선 필수 추가 기능**

**목적:** 지출결의서 작성자가 사업과 사업비 항목을 선택했을 때 요구되는 증빙서류를 확인하고 빠짐없이 연결할 수 있도록 한다.

**기능 규칙:**

1. 사업명, 재원, 예산 비목·세목을 선택하면 적용 가능한 **증빙 기준**을 자동 조회한다.
2. 해당 기준에 따라 서류 목록, 필수/선택 구분, 적용 조건, 서류별 안내를 표시한다.
3. 동일한 비목이라도 사업 또는 지원기관이 다르면 다른 증빙 기준을 적용할 수 있다.
4. 필수 서류별 파일 링크와 첨부 여부를 기록한다. 하나의 서류 종류에 여러 파일이 필요할 수 있도록 확장 가능한 구조를 사용한다.
5. 미첨부 필수서류의 수와 이름을 표시하고 누락 경고를 제공한다.
6. 결재 요청 시 필수서류 첨부 상태를 검증하고, 미첨부 시 요청 차단 또는 승인된 예외 사유 기록 방식을 설정할 수 있다.
7. 서류별 첨부일·첨부자·파일명·저장 경로를 조회할 수 있다.
8. 증빙 기준은 관리자가 별도 시트에서 추가·수정·비활성화할 수 있다.
9. 기존 지출결의서의 적용 기준을 추적할 수 있도록 기준 버전 또는 적용일을 기록한다.
10. 지출결의 번호별 증빙 목록을 정산 목록으로 출력할 수 있다.

**초기 표시 예시(법적·행정적 확정 목록이 아님):**

| 지출 항목 예시 | 안내할 수 있는 증빙서류 예시 |
|---|---|
| 강사비 | 강의계획서, 강사 이력서, 강의확인서, 지급명세서, 원천징수 관련 서류 |
| 회의비 | 회의계획서, 회의록, 참석자 명단, 카드 영수증 |
| 물품구입비 | 견적서, 거래명세서, 세금계산서 또는 영수증, 검수확인서, 물품 사진 |
| 여비 | 출장신청서, 출장결과보고서, 교통비 영수증, 숙박비 영수증 |

> 위 서류는 화면·기능 설명을 위한 **예시**다. 실제 필수서류, 생략 조건, 개인정보 수집 범위 및 보존 기한은 사업의 지원기관 지침을 확인해 설정해야 한다.

**증빙 기준 설정 데이터(제안):**

| 필드 | 설명 |
|---|---|
| 기준 ID | 증빙 규칙 고유 식별자 |
| 사업 ID 또는 사업 유형 | 적용 대상 사업 |
| 지원기관 | 규칙 적용 기관 |
| 재원 구분 | 보조금 / 자부담 등 |
| 비목·세목 | 지출 분류 |
| 서류 유형 | 영수증, 계약서 등 |
| 필수 여부 | 필수 / 선택 / 조건부 |
| 적용 조건 | 금액, 거래 형태 등에 따른 조건 |
| 적용 시작일·종료일 | 기준의 유효기간 |
| 안내 문구 | 첨부 시 유의사항 |
| 활성 상태 | 현재 사용 여부 |

**화면 동작 예:**

`사업 선택 → 예산 항목 선택 → 필요서류 목록 자동 표시 → 증빙 파일 저장 및 링크 등록 → 누락 여부 자동 확인 → 결재 요청`

## 7. 데이터 연결 및 무결성

- `사업 ID`: 사업·예산·지출·정산 연결의 기본 키
- `예산 항목 ID`: 사업·재원·비목·세목 조합 식별
- `지출결의 번호`: 결의서·결재·증빙 연결의 기본 키
- `증빙 기준 ID`: 어떤 첨부 규칙이 적용되었는지 식별
- `증빙 파일 ID`: 서류별 첨부 파일 식별
- 중복 번호, 누락된 사업 ID, 존재하지 않는 예산 항목 참조를 감지
- 승인·반려·지급 완료 상태를 구분하고 집계에 반영
- 수정 시 중복 집계되지 않도록 하나의 원본 데이터 표를 기준으로 계산

## 8. 초보자를 위한 화면 및 사용성

- 입력 셀·자동 계산 셀을 서로 다른 서식으로 구별
- 선택형 드롭다운으로 사업·비목·세목·서류 유형 입력
- 필수 입력 누락·예산 초과·첨부 서류 누락 시 명확한 경고
- 지출결의서 출력 양식은 별도 인쇄 서식으로 제공
- 가급적 기본 함수, Excel 표, 데이터 유효성 검사, 조건부 서식, 피벗테이블 등으로 구현
- 반복 버튼, PDF 자동 생성 등 고급 편의 기능에만 VBA 도입 검토
- 시트별 간단한 사용 안내와 입력 예시 제공

## 9. 기술·보안·운영 제약

### 9.1 1차 권장 기술

- Microsoft Excel 데스크톱 버전 기반 `.xlsx`
- 기본 기능: Excel 표, 함수, 드롭다운, 조건부 서식, 차트, 하이퍼링크
- 매크로 없이 구현 가능한 핵심 기능을 우선 개발
- VBA 매크로가 필요한 자동화는 별도 `.xlsm` 고도화 단계에서 결정

### 9.2 파일·공동 작업 운영

- 기관에서 승인한 보관 위치를 사용하고 정기적으로 백업
- 파일명 및 폴더 규칙 수립(예: `사업연도/사업ID/지출결의번호/증빙파일`)
- 경로가 끊긴 첨부파일에 대한 점검 필요
- 여러 사용자가 하나의 파일을 동시 수정하는 방식은 버전·저장소·매크로 사용 여부에 따라 제약이 있으므로 실제 환경에서 검증
- 업무별 입력 책임자·승인 책임자 지정
- 개인정보 및 계좌정보 포함 문서의 접근 권한·보존 기간은 기관 지침 준수

### 9.3 법령·지침 적용

- 특정 보조금 유형, 지원기관, 지역, 서식, 사업비 인정 기준은 사용자로부터 아직 확인되지 않음
- 따라서 본 문서는 **제품 기능 설계**이며 보조금 정산 요건에 대한 법률적·행정적 적합성을 확정하지 않음
- 실제 도입 전 각 보조금 지원기관의 최신 집행·증빙·정산 지침 및 내부 결재규정을 반영해야 함

## 10. 개발 우선순위

### 1차 MVP — 실제 사용을 위한 최소 필수 기능

1. 사업 등록 및 사업별 데이터 구분
2. 예산 편성·잔액·초과 경고
3. 지출결의서 입력·조회·인쇄 양식
4. **사업비별 필요 증빙서류 기준 설정 및 자동 표시**
5. **증빙파일 링크 연결, 첨부 확인, 누락 경고**
6. 결재 상태 기록 및 승인 집계
7. 정산용 집행내역·증빙 목록 출력
8. 기본 대시보드

### 2차 고도화

- 지출결의서 및 정산 보고서 PDF 저장 자동화
- 검색·필터·대시보드 고도화
- 조건부 증빙 기준의 고급 검증
- 제출용 지원기관별 정산 양식
- 입력·수정 이력 관리 강화

### 후속 확장 검토

- 사용자 인증 기반 접근 제어
- 전자서명 및 결재 자동 알림
- 웹 기반 공동 작업 시스템
- 회계 시스템 또는 승인된 기관 데이터와의 연동

| T-06 | 사업별로 다른 증빙 기준 설정 | **동일 지출 항목이라도 해당 사업 기준에 맞는 목록 표시** |

| T-12 | 지출결의서 인쇄 | 필수 내용이 양식에 정상 출력됨 |
| T-13 | 사업별 정산 보고서 생성 | 원본 지출내역과 합계 일치 |

## 12. 실제 제작 전 확인할 미확정 사항

1. 적용 보조금 유형과 지원기관, 지출·정산 관련 공식 지침
2. 사업비 비목·세목 체계와 항목별 **실제 필수 증빙서류 목록**
3. 지출결의서 및 정산 보고서의 기관 지정 서식 유무
4. 결재 단계, 승인 권한, 서류 누락 시 예외 처리 원칙
5. 사용자 수 및 동시 편집 필요 여부
6. 기관에서 사용 중인 Excel 버전과 매크로 허용 여부
7. 증빙 파일의 공용 저장 위치, 접근 권한, 백업 방식
8. 정산·예산 집계 시 승인일, 지급일 등 어떤 기준일을 사용할지
